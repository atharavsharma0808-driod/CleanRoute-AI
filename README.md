# ♻️ CleanRoute-AI

An intelligent waste management system that helps prioritize garbage reports based on their severity and location.

CleanRoute-AI is designed to make garbage reporting smarter by assigning a **priority score** to reported waste issues. This can help authorities identify which problems need immediate attention.

---

## 🚀 Features

- 🗑️ Report garbage issues
- ⚠️ Priority scoring based on severity
- 📍 Location-based priority calculation
- 🏥 Higher priority for sensitive locations such as hospitals
- 📊 Generate a detailed garbage report
- 🖥️ User-friendly Python GUI

---

## 🧠 How It Works

The system calculates a priority score using factors such as:

1. **Severity of the garbage issue**
   - High
   - Medium
   - Low

2. **Location type**
   - Hospital
   - School
   - Residential area
   - Public area

The final priority score helps determine which garbage reports should be addressed first.
